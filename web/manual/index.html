User manual · @VERSION@

A four-operator FM instrument.

Felucca-RDX turns the M-VAVE FM-1 into a focused, eight-voice synthesizer inspired by the sound architecture and workflow of the Yamaha reface DX.

One instrument, not a groovebox. Felucca-RDX is monotimbral. It does not provide multitrack operation, a mixer, or track switching.

1. Getting started

Install Felucca-RDX from the web installer with a USB data cable and Chrome or Edge. The normal installer preserves compatible Felucca-RDX user sounds and settings. Choose Fresh install only when you intentionally want to erase user data and all system settings.

Before installing Keep the FM-1 powered and connected until the installer reports completion. If another application owns the MIDI port, close it first.

Controls used by RDX

PRESETSSelects the current sound from the active list.
ALGORITHMChanges the 4-operator algorithm and opens the Algorithm page.
SELECTSelects rows in EDIT pages and controls Touch Wah position when active.
KNOB 1–4Edit the four cards or the four operator values shown on screen.
HOMEReturns to performance controls. Pressing it again stays on HOME.

2. HOME and performance

HOME is the main playing page. The lower-left label reads List – Sound; the four knobs edit performance values without entering the deep operator editor.

KnobControlRangeMeaning
1MODEPoly / MonoFull / MonoLeg.Poly provides up to eight voices. MonoFull retriggers the full voice. MonoLeg. changes pitch without retriggering when notes overlap.
2PORTA0–127Portamento time. Higher values produce a slower glide. It is most obvious in the two mono modes.
3GAIN−24…+24 dBPer-sound clean output trim. Factory and Selected sounds have calibrated defaults; positive gain does not intentionally add distortion.
4Trans.−24…+24 semitonesMaster transpose applied to both the built-in keyboard and incoming MIDI, with MIDI-note boundary protection.

OCT− and OCT+ add a further −3…+3 octave performance shift. A non-zero shift appears in the centre of the status bar as, for example, OCT +1.

Legato playing In MonoLeg., hold the first note and play another. The same voice continues and follows PORTA instead of starting a chromatic ladder of new notes.

3. Sound lists

RDX separates the synthesizer engine from its sound organisation. A sound can belong to a list and also carry a type such as Lead, Pad, Keys or Bass.

ListContentsUse

Selected21 curated SysEx voicesAdditional ready-to-play sounds embedded in the firmware.
UserImported or edited voicesLoaded from the Web Editor. An auditioned sound appears immediately on HOME with its own name.

Turn PRESETS to choose a sound. Library import and User-slot management are performed in the Web Editor.

4. Four-operator FM and algorithms

Each voice has four sine-based operators. A carrier is heard at the output; a modulator changes another operator and creates harmonics. The algorithm defines those connections. Squares below are carriers, circles are modulators.

CarrierModulatorLines point toward the operator being modulated.

Turn ALGORITHM at any time to open this page and choose Algorithm 1–12. KNOB 1–4 switch OP1–OP4 on or off. A disabled operator and its connections are dimmed on the device.

Why the sound can change dramatically An algorithm changes which operators are audible and which create harmonics. Lower the operator levels before exploring if you want subtler changes.

5. Envelopes

Operator EG

Every operator has a four-stage level envelope: four RATE values define how quickly it moves, and four LEVEL values define the destinations. Press EDIT to reach OP EG, use SELECT to choose OP1 RATE, OP1 LEVEL … OP4 LEVEL, then use the four knobs for stages 1–4.

OP1OP2OP3OP4
  • A higher RATE generally reaches the destination faster.
  • LEVEL changes the loudness of a carrier or the harmonic intensity of a modulator.
  • Stage 4 is the release destination after note-off. Carrier Level 4 is constrained to zero.
  • The screen uses fixed red, purple, cyan and yellow traces, independent of the selected theme.

Pitch EG

Press ENV to alternate between PEG RATE and PEG LEVEL. RATE 1–4 set the speed of four pitch segments; LEVEL 1–4 set their pitch destinations around the centre value. The graph has a bipolar centre line because this envelope moves pitch rather than loudness.

On the OP MOD page, PITCH EG can be enabled separately for each operator.

6. RDX LFO

Press LFO to open the common low-frequency oscillator. The graph follows the selected waveform, and the four knobs edit:

ParameterRangeFunction
WAVESINE, TRI, SAW+, SAW−, SQR, S&H8, S&HShape of the repeating or sample-and-hold modulation.
SPEED0–127LFO rate, using the RDX frequency curve.
DELAY0–127Delays and fades in the LFO after note-on.
PMD0–127Common pitch-modulation depth.

Operator-specific LFO AMD and LFO PMD switches live on EDIT page 4. AMD changes operator level; PMD allows the common pitch modulation to affect that operator.

7. The six EDIT pages

Press EDIT repeatedly to move through the RDX editor. On matrix pages, SELECT chooses a row and KNOB 1–4 edit OP1–OP4.

ALGORITHM

Choose one of 12 structures with the ALGORITHM encoder. KNOB 1–4 turn each operator on or off.

OP EG

Eight selectable rows: RATE and LEVEL for each operator. The four knobs address envelope stages 1–4.

SCALING

RATE scaling, left/right keyboard depth and left/right curve for every operator. Curves are −LIN, −EXP, +EXP and +LIN.

OP MOD

Per-operator LFO AMD amount, LFO PMD on/off and Pitch EG on/off.

OP LEVEL

Velocity sensitivity, output level, feedback waveform (SAW/SQR) and feedback amount for each operator.

FREQUENCY

Ratio/fixed mode, coarse, fine and detune. RESULT shows the resulting ratio or fixed-frequency form.

Keyboard level scaling

Scaling changes an operator's contribution across the keyboard around middle C. Negative curves attenuate away from the breakpoint; positive curves boost. Use it to keep bass notes clean, brighten upper notes, or make modulation react differently by register.

Frequency modes

  • RATIO tracks the played note. Coarse and Fine define a harmonic or inharmonic multiple.
  • FIXED keeps the operator at a fixed frequency, useful for metallic, percussive and formant components.
  • DETUNE offsets an operator around its centre value to add beating or width.

Feedback

Feedback returns an operator's output to itself, increasing brightness and complexity. SAW and SQR use different feedback waves. High feedback can become noisy or aggressive; reduce OUT LEVEL or FEEDBACK if needed.

8. Serial stereo effects

RDX uses a serial insert chain. The processed output of FX1 becomes the input of FX2.

RDX voice→FX1→FX2→Output

On the first FX page, KNOB 1/2 control FX1 TYPE/SEND and KNOB 3/4 control FX2 TYPE/SEND. Press FX again for the parameters of FX1, then FX2. THRU displays a dash instead of SEND and has no parameters. Flanger always receives full serial input, so its SEND card is hidden.

Passes sound unchanged.

No parameters

INFO performance values

INFO shows Core 0/Core 1 load and peaks, RDX per-voice render time, wall time, waiting and effect timing. These are diagnostic values; the release firmware no longer interrupts playing with a large AUDIO LATE popup.

10. Web tools

InstallerInstall the normal or Fresh package over Web MIDI. EditorImport SysEx/ZIP libraries, audition voices and write User slots. EmulatorPlay the latest source build in a browser without hardware.

Library workflow

  1. Connect the FM-1 by USB and open the Editor in Chrome or Edge.
  2. Import individual .syx files or a ZIP library. Search by voice number or name.
  3. Use Audition to hear a voice immediately, or send it to a User slot.
  4. The FM-1 switches to the imported voice and HOME displays its name.

The browser emulator runs the same RDX/UI source but does not model AC79 dual-core timing, DMA or the physical audio buffer. Use real hardware for CPU and AUDIO LATE testing.

Troubleshooting

  • No sound after an Editor selection: update both firmware and Editor, reconnect USB, then audition again.
  • Installer cannot find FM-1: use a data cable, grant MIDI SysEx permission, and close other MIDI applications.
  • A sound clips: lower HOME GAIN or effect LEVEL. Positive GAIN is clean but the combined operator/effect signal still needs headroom.
  • Old Felucca data behaves strangely: the normal package migrates incompatible storage automatically; use Fresh install only if a complete reset is desired.

1. 开始使用

请使用 USB 数据线，通过 Chrome 或 Edge 打开网页安装器。普通安装会保留兼容的 Felucca-RDX User 音色和设置；只有在你明确需要删除用户数据及全部系统设置时，才勾选全新安装。

安装前 安装器提示完成之前，请保持 FM-1 供电和 USB 连接。如果其他程序正在占用 MIDI 端口，请先将其关闭。

2. HOME 与演奏

HOME 是主要演奏页面。左下角以 音色集 – 音色名 显示当前声音，四个旋钮提供常用演奏参数。

旋钮参数范围作用
1MODEPoly / MonoFull / MonoLeg.Poly 最多八复音；MonoFull 每次按键完整重触发；MonoLeg. 在按键重叠时沿用同一声部并连续改变音高。
2PORTA0–127滑音时间。数值越大，音高滑动越慢；在两个单音模式中最为明显。
3GAIN−24…+24 dB每个音色的干净输出增益。Factory 和 Selected 音色已有响度校正默认值。
4Trans.−24…+24 半音主移调，同时作用于 FM-1 自带键盘和 MIDI 输入，并对 MIDI 音符边界进行保护。

OCT− 和 OCT+ 可再提供 −3…+3 个八度的演奏移调。非零值会显示在状态栏正中，例如 OCT +1。

连奏方法 在 MonoLeg. 中，按住第一个音再弹第二个音。引擎会沿用同一个声部并按 PORTA 连续改变音高，而不是快速触发中间的半音。

3. 音色集

RDX 将合成引擎与音色整理方式分开。一个音色可以属于某个 LIST，同时也可以具有 Lead、Pad、Keys 或 Bass 等类型。

LIST内容用途
Factory32 个 reface DX 原厂音色核心参考音色；LegendEP 和 DynaLead 位于最前面。
Selected21 个精选 SysEx 音色内置在固件中的扩展音色。
User导入或编辑的音色由 Web Editor 写入。Audition 后，HOME 会立即显示新音色名称。

旋转 PRESETS 选择音色。音色库导入和 User 槽位管理在 Web Editor 中完成。

4. 四算子 FM 与算法

每个声音由四个以正弦波为基础的算子组成。载波直接送到输出；调制器改变另一个算子，从而产生泛音。算法决定算子之间的连接。下图中方形代表载波，圆形代表调制器。

载波调制器连线指向被调制的算子。

随时旋转 ALGORITHM 都会打开本页，并在 Algorithm 1–12 之间选择。KNOB 1–4 分别控制 OP1–OP4 开关；关闭的算子及其连线会在真机上变暗。

为什么切换算法会明显改变声音 算法会改变哪些算子可以直接听到、哪些算子负责制造泛音。如果希望变化温和一些，可以先降低算子 OUT LEVEL。

5. 包络

算子 EG

每个算子都有四阶段电平包络：四个 RATE 决定移动速度，四个 LEVEL 决定各阶段的目标。按 EDIT 进入 OP EG，用 SELECT 选择 OP1 RATE、OP1 LEVEL……OP4 LEVEL，再用四个旋钮编辑第 1–4 阶段。

OP1OP2OP3OP4
  • RATE 越高，通常越快到达目标。
  • LEVEL 会改变载波响度，或改变调制器产生泛音的强度。
  • 第 4 阶段是松开按键后的释放目标；载波的 Level 4 被限制为 0。
  • OP1–OP4 固定使用红、紫、青、黄，不受主题影响。

Pitch EG

按 ENV 在 PEG RATE 和 PEG LEVEL 两页之间切换。RATE 1–4 设置四段音高变化的速度；LEVEL 1–4 设置相对于中心音高的目标。由于它控制的是音高，曲线图具有正负变化的中心线。

在 OP MOD 页面中，可以为每个算子分别打开或关闭 PITCH EG。

6. RDX LFO

按 LFO 打开公共低频振荡器。屏幕曲线会随波形改变，四个旋钮控制：

参数范围功能
WAVESINE、TRI、SAW+、SAW−、SQR、S&H8、S&H选择周期波形或采样保持波形。
SPEED0–127按照 RDX 频率曲线调整 LFO 速度。
DELAY0–127按键后延迟并渐入 LFO。
PMD0–127公共音高调制深度。

每个算子自己的 LFO AMD 和 LFO PMD 位于 EDIT 第 4 页。AMD 改变算子电平，PMD 决定公共音高调制是否作用于该算子。

7. 六个 EDIT 页面

反复按 EDIT 在六个 RDX 编辑页面之间切换。在矩阵页面中，用 SELECT 换行，KNOB 1–4 分别编辑 OP1–OP4。

ALGORITHM

用 ALGORITHM 旋钮选择 12 种结构；KNOB 1–4 分别打开或关闭四个算子。

OP EG

共八行：每个算子的 RATE 和 LEVEL。四个旋钮对应包络阶段 1–4。

SCALING

每个算子的 Rate Scaling、左右深度和左右曲线。曲线包括 −LIN、−EXP、+EXP、+LIN。

OP MOD

每个算子的 LFO AMD 数值、LFO PMD 开关和 Pitch EG 开关。

OP LEVEL

力度灵敏度、输出电平、反馈波形（SAW/SQR）和反馈量。

FREQUENCY

Ratio/Fixed 模式、Coarse、Fine 和 Detune；RESULT 显示最终比率或固定频率形式。

Keyboard Level Scaling

以中央 C 附近为基准，让算子的贡献随键盘位置变化。负曲线会在远离基准处衰减，正曲线会增强。它可以保持低音清晰、让高音更明亮，或让不同音区具有不同调制强度。

频率模式

  • RATIO 跟随演奏音符，Coarse 和 Fine 决定谐波或非谐波倍频。
  • FIXED 保持固定频率，适合金属、打击乐和共振峰成分。
  • DETUNE 在中心值附近偏移算子频率，用来产生拍频和宽度。

Feedback

反馈会把算子的输出送回自身，提高亮度和复杂度。SAW 与 SQR 使用不同反馈波形。过高的反馈可能产生噪声或强烈音色，此时可降低 OUT LEVEL 或 FEEDBACK。

10. 网页工具

安装器通过 Web MIDI 安装普通版或全新安装版。 编辑器导入 SysEx/ZIP、Audition 音色并写入 User 槽位。 模拟器无需硬件，在浏览器中演奏最新源码版本。

Library 使用流程

  1. 通过 USB 连接 FM-1，并使用 Chrome 或 Edge 打开 Editor。
  2. 导入单个 .syx 文件或 ZIP 音色库，可按编号或名称搜索。
  3. 点击 Audition 立即试听，或写入一个 User 槽位。
  4. FM-1 会切换到导入音色，HOME 同步显示其名称。

网页模拟器运行相同的 RDX 和 UI 源代码，但不模拟 AC79 双核调度、DMA 和真机音频缓冲。CPU 和 AUDIO LATE 测试仍应以真机为准。

常见问题

  • Editor 选择音色后无声：请同时更新固件和 Editor，重新连接 USB 后再 Audition。
  • 安装器找不到 FM-1：确认使用数据线、允许 MIDI SysEx 权限，并关闭其他 MIDI 程序。
  • 音色削波：降低 HOME GAIN 或效果器 LEVEL。正 GAIN 本身是干净增益，但算子和效果叠加后仍需保留余量。
  • 旧 Felucca 数据异常：普通安装会自动迁移不兼容数据；只有需要彻底重置时才使用全新安装。
